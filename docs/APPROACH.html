A Judge That Learns from an ExpertСудья, который учится у эксперта

Plata track · Hack Day Barcelona 2026Трек Plata · Hack Day Barcelona 2026

1A polite answer can still be wrongВежливый ответ всё равно может быть неверным

The assistant agrees: Uber, August, 526 MXN. The bank context says completed transactions total 426 MXN. Plata's expert labelled this conversation bad. The only way to catch it is to recompute.Ассистент соглашается: Uber, август, 526 MXN. В данных банка завершённые операции дают 426 MXN. Эксперт Plata пометил этот диалог как bad (плохой). Поймать ошибку можно только пересчётом.

2The task in one pictureЗадача на одной картинке

Learn an expert's rules from labelled conversations. Save them as artifacts: rules plus an explanation. Then judge new conversations. The score rewards accuracy and a clear explanation.Из диалогов с пометками эксперта учим его правила. Сохраняем результат: правила и объяснение. Потом оцениваем новые диалоги. В оценке важны точность и понятное объяснение.

3How adapt learnsКак adapt учится

Three steps, all from the training set. A rule that raises even one false alarm on an expert-approved conversation may not decide. It moves to boundary and stays in the explanation as a rejected hypothesis.Три шага, все — по обучающим диалогам. Если правило хоть раз назвало плохим диалог, который эксперт признал хорошим, решать ему нельзя. Оно уходит в «границу» и остаётся в объяснении как отвергнутая гипотеза.

4How eval decidesКак eval выносит вердикт

Rules are checked in priority order. The first violated rule gives bad, with the assistant's own quote. If none is violated, the answer is good.Правила проверяются по приоритету. Первое нарушенное правило даёт bad, вместе с цитатой из ответа ассистента. Если нарушений нет — good.

5The explanation is the implementationОбъяснение — это и есть то, что работает

One manifest produces the explanation and drives the predictions. Its SHA-256 is stored in run_meta.json. The text a judge reads is the rule set that predicts.Один файл с правилами порождает и объяснение, и предсказания. Его цифровой отпечаток (SHA-256) записан в run_meta.json. Текст, который читает жюри, — это ровно те правила, что делают предсказания.

Jury criterionКритерий жюриWhat the explanation showsЧто показывает объяснение
Clear criteriaПонятные критерииEvery rule as a plain condition, e.g. “Recalculate completed merchant transactions before confirming a proposed amount”Каждое правило — простым условием, например: «Пересчитать завершённые операции по продавцу, прежде чем подтверждать названную сумму»
Clear prioritiesПонятные приоритетыRules sorted by priority; the first violation winsПравила стоят по приоритету; решает первое нарушение
Links to training examplesСсылки на обучающие примерыReal train IDs with the expert's labels and quotesНастоящие ID обучающих диалогов, пометки эксперта и цитаты
Clear boundariesПонятные границыRejected hypotheses, each with its conditionОтвергнутые гипотезы, у каждой своё условие
Consistency with the implementationСовпадение с реализациейSame manifest for text and predictions; hash in run_meta.jsonОдин файл с правилами и для текста, и для предсказаний; отпечаток в run_meta.json

An independent structural check found all five present on every adapt run. Jury points themselves are not claimed.Независимая проверка структуры нашла все пять пунктов в каждом запуске adapt. Сколько баллов даст жюри, мы не обещаем.

6Optional model layerНеобязательный слой с моделью

A model answers yes, no or unknown, and must quote the assistant. It can also propose rules for bad cases nothing explains. Every proposal is verified on all of train first.Модель отвечает «да», «нет» или «не знаю» и обязана привести цитату ассистента. Ещё она может предложить правила для плохих диалогов, которые ни одно правило не объяснило. Каждое предложение сначала проверяется на всех обучающих диалогах.

Default: Claude Sonnet 5.5; open-weight Qwen3.8-27B passes the same hidden-rule test and is the cheap open path; no key → deterministic rulesПо умолчанию — Claude Sonnet 5.5; открытая Qwen3.8-27B проходит тот же тест на спрятанное правило и даёт дешёвый открытый путь; без ключа — только правила Hidden-rule test: we removed the MIN_INTEREST family and let the model re-discover it. Claude Sonnet 5.5 did (4 of 4, 0 false alarms, $4.07) and so did open-weight Qwen3.8-27B (4 of 4, 0 false alarms, with a longer request deadline, ~10x cheaper per token); Gemma phrased it but failed verification; gpt-oss-120b from scratch did not.Проверка: мы спрятали одно правило (MIN_INTEREST) и попросили модель найти его заново. Sonnet 5.5 нашёл его (4 из 4, без ложных тревог, $4.07) и открытая Qwen3.8-27B тоже (4 из 4, без ложных тревог; пришлось дольше ждать ответ; примерно в 10 раз дешевле за токен). Gemma правило сформулировала, но проверка его не пропустила; gpt-oss-120b с нуля — не нашла.

Macro accuracy over four topics. The public test is not a clean holdout; CV is the honest estimate.Точность — среднее по четырём темам. Публичный тест — не чистая проверка; честная оценка — перекрёстная проверка (CV).

Next stepsЧто дальше

aModel councilСовет моделей

Two or three open-weight models (Qwen, Gemma, gpt-oss) propose hypotheses on the same bad/good pairs. Proposals are merged; the same verifier checks them. Gemma already phrased the hidden rule almost word for word, but the verifier rejected it as too noisy.Две-три открытые модели предлагают правила по одним и тем же парам диалогов, предложения объединяются, проверка та же. Gemma уже почти дословно сформулировала спрятанное правило, но проверка его отклонила.

bMeaning checksПроверки смысла

Semantic checks for violations that have no numbers, like the 4 public-test misses.Проверки смысла для ошибок без чисел — например, для 4 пропусков на публичном тесте.

cHonest accuracy estimateЧестная оценка точности

Grouped cross-validation inside adapt, so the artifacts report an honest expected accuracy.Перекрёстная проверка прямо внутри обучения: вместе с результатом выдаётся честная оценка точности.

dOpen-weight pathОткрытый путь

Qwen passed the hidden-rule test with a longer deadline; next: make that the Qwen default and run the full Qwen induction on the public set.Qwen прошла тест на спрятанное правило при более долгом ожидании ответа. Дальше: сделать это настройкой Qwen по умолчанию и прогнать полный поиск правил на публичных данных.

9Try itЗапуск

Docker containers get no API key. Start each adapt with an empty artifacts folder. Bring your own example: a dialog and a context as two JSON files.Контейнеры Docker не получают ключ API. Каждый adapt запускайте с пустой папкой artifacts. Можно принести свой пример: диалог и данные банка (context) в двух JSON-файлах.

mkdir -p out/public_input out/public_artifacts out/public_output
python3 src/prepare_inputs.py --train data/public_train.csv --test data/public_test.csv --out-dir out/public_input
docker build -t plata-judge .

1AdaptAdapt (обучение)

docker run --rm \
  -v "$PWD/out/public_input:/input:ro" \
  -v "$PWD/out/public_artifacts:/artifacts" \
  plata-judge adapt

2EvalEval (оценка)

docker run --rm \
  -v "$PWD/out/public_input:/input:ro" \
  -v "$PWD/out/public_artifacts:/artifacts:ro" \
  -v "$PWD/out/public_output:/output" \
  plata-judge eval
